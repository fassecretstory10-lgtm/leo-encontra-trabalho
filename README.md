# Leo Encontra Trabalho!

A personal career discovery and application workspace.

## Stack
- React + TypeScript + Vite
- Cloudflare Pages / Workers
- Cloudflare D1 for persistent job and application data (Phase 2)
- Cloudflare R2 for documents (later phase)

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Connect this repository to Cloudflare Pages. Build command: `npm run build`. Output directory: `dist`.

The application is being developed in phases. Current UI data is clearly marked as illustrative until live job-source integrations are connected.
